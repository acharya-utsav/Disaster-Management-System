
# Disaster Management & Rescue Coordination System

## Mini Project
Object Oriented Programming (C++)

## Developed By
Utsav Acharya  
Computer Engineering, IOE, TU

## Project Description
A console-based C++ application designed to manage disaster records, rescue teams, and resources using Object-Oriented Programming.

## Features
- Report, view, search, update, and delete disaster records
- Rescue Team Management
- Resource Management
- Dashboard and statistics
- Report generation
- File handling for persistent data storage

## Technologies Used
- C++
- Code::Blocks
- GCC Compiler
- Git and GitHub

## How to Run
1. Open `main.cpp` in Code::Blocks.
2. Build and run the project.
3. Use the menu to access different features.
